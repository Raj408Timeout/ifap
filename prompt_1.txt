Prompt 1
You are acting as a Principal Architect, Staff Engineer, Platform Engineer, Product Architect, and Lead Python Developer.

Your task is to design and build an enterprise-grade AI platform called:

Intelligent Feedback & Assessment Platform (IFAP)

Business Problem
----------------

Organizations currently maintain questionnaires manually for different business functions.

Examples:

- Customer Feedback
- Employee Engagement
- Compliance Reviews
- Risk Assessments
- Healthcare Intake Forms
- Product Surveys
- Vendor Assessments
- Audit Questionnaires

Today these are manually created, maintained and analyzed.

The platform must allow dynamic questionnaire generation through AI using a knowledge base and configurable templates.

The system must start with the Questionnaire Generation use case but be designed as a multi-agent enterprise platform.

High Level Goals
----------------

1. User interacts through chatbot UI
2. User describes business need
3. AI identifies relevant questionnaire templates
4. AI generates questionnaire
5. User reviews and modifies questionnaire
6. Responses are collected
7. Analytics generated
8. Architecture supports future AI agents

Future agents may include:

- Analytics Agent
- Insights Agent
- Recommendation Agent
- Trend Detection Agent
- Sentiment Agent
- Quality Agent
- Compliance Agent
- Risk Agent

The architecture must support plugging in new agents without changing existing code.

Multi-Agent Design
------------------

Design following agents:

1. Intent Agent
   Understand customer need

2. Template Retrieval Agent
   Retrieve questionnaire templates via RAG

3. Questionnaire Builder Agent
   Build questionnaire

4. Validation Agent
   Validate generated questionnaire

5. Analytics Agent (future)

6. Recommendation Agent (future)

------------------

 ->
Validation Agent
 ->
Response
